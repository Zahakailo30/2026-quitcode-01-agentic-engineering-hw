  полями.
- Встановлення `gh` через `winget` зависло на UAC-підтвердженні — не стали
  чекати, пішли обхідним шляхом.

## A/B промптів

Та сама підзадача («історія раундів») двома промптами — базовим і
структурованим; кожен у чистому контексті, та сама модель. Деталі —
[`ab-experiment.md`](ab-experiment.md).

- Структурований коштував **+11% токенів** (55.7k проти 50.2k) за ту саму
  кількість ітерацій.
- `lint` і `build` пройшли **обидва** варіанти — різницю видно лише очима.
- У базового: вигаданий CSS-токен (невидимий фон), лічильник не скидається
  після «Reset score» (запис `#4` при нульовому рахунку), блок опинився під
  кнопкою й зламав центрування.
- Висновок: економія на промпті не зникає, а переїжджає в рев'ю. Найбільше
  дали не «роль» і «формат», а **обмеження** та **критерії приймання**.

## Спостереження

1. Перевіряти встановлену версію дизайн-системи прямо в `node_modules`, а не
   покладатись на загальну пам'ять про її API.
2. Прогнати `npm run lint` одразу після першої чернетки з обробниками подій,
   а не лише перед комітом.
3. Для GitHub Pages симулювати реальний URL (з base path) локально ще до
   деплою — одразу видно, чи коректні шляхи до асетів.
